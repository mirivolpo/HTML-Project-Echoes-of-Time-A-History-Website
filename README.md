# Echoes of Time: Apollo 11

פרויקט אתר היסטוריה קטן (מוזיאון מקוון) המציג את סיפור הנחיתה הראשונה על הירח (משימת אפולו 11).

## עמודי האתר
האתר מורכב מ-4 עמודי HTML מקושרים המספרים את הסיפור המלא:
* **origins.html** - איך הכל התחיל (המירוץ לחלל).
* **figures.html** - האנשים שמאחורי המשימה (ניל ארמסטרונג, באז אולדרין ומייקל קולינס).
* **artifacts.html** - החפצים שהושארו על הירח ואלו שהובאו לכדור הארץ (כולל גלריית תמונות).
* **legacy.html** - המורשת של המשימה ואיך זוכרים אותה היום (כולל הקלטת אודיו היסטורית).

## איך להריץ
הפרויקט בנוי ב-HTML נקי. אין צורך בהתקנות מיוחדות.
פשוט הורד את הקבצים, ופתח את הקובץ `origins.html` בכל דפדפן כדי להתחיל לגלוש.
